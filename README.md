# Big Bite - Caso 6 (Hamburguesería)

Entrega del Frontend responsivo y navegable.

## Características incluidas:
- **Diseño Responsivo:** Adaptable a dispositivos móviles y escritorio.
- **Navegabilidad:** Enlaces funcionales con desplazamiento suave.
- **Interactividad (JS):** 
  - Ventana modal para inicio de sesión.
  - Panel lateral deslizable para el Carrito de Compras.
  - Lógica de suma de precios y contador de productos.
- **Estilos (CSS):** Paleta de colores Dark Mode (Gourmet) e implementación de Sketch.
